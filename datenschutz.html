Datenschutzerklärung – Agentic OS

Worum es geht

Agentic OS ist eine selbst gehostete Anwendung. Sie läuft ausschließlich auf dem Server oder Rechner der Person, die sie installiert hat. Es gibt keinen zentralen Dienst und keine Server des Herausgebers, über die Daten laufen.

Welche Google-Daten genutzt werden

Wer die Google-Anmeldung einschaltet, erlaubt den Zugriff auf:

  • Google Kalender: Termine lesen, anlegen und ändern,
  • Gmail: E-Mails lesen und Entwürfe anlegen,
  • Google Drive: Dateien lesen und ablegen (Datenaustausch-Ordner),
  • die E-Mail-Adresse des Kontos, um die Anmeldung anzuzeigen.

Wo die Daten bleiben

  • Der Zugangsschlüssel (Refresh-Token) wird nur lokal auf der eigenen Installation gespeichert.
  • Google-Daten werden nur auf Anforderung der angemeldeten Person abgerufen und verarbeitet.
  • Der Herausgeber von Agentic OS erhält keine Daten. Es gibt kein Tracking, keine Werbung und keinen Verkauf von Daten.
  • Lässt die Person ein KI-Modell mit Inhalten arbeiten, gehen diese Inhalte an den KI-Anbieter, den sie selbst eingerichtet hat, und zwar nur für diese Anfrage.

Google API Services User Data Policy

Die Nutzung und Weitergabe von Daten, die Agentic OS von Google-APIs erhält, hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen an die eingeschränkte Nutzung („Limited Use“). Google-Daten werden nicht zum Training allgemeiner KI-Modelle verwendet.

Zugriff widerrufen und Daten löschen

Die Verbindung lässt sich jederzeit in Agentic OS unter Einstellungen → Google trennen. Dabei wird der gespeicherte Schlüssel gelöscht. Zusätzlich kann der Zugriff unter myaccount.google.com/permissions entzogen werden.
